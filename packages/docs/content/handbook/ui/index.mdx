Vem UI provides controls, navigation, and feedback for React applications. Install one package and receive component fixes through ordinary package updates. Your application keeps its router, content, and layouts.

## Add the package

Use React 19 and React DOM 19:

```sh
npm install @hyecompany/vem-ui
```

Include `@hyecompany/vem-ui/styles.css` once at your application entry. The package ships its own CSS; Tailwind and shadcn source installation are not required.

## Update the package

Use your package manager to update the dependency and review the release notes. Component implementation stays in Vem; application branding stays in your stylesheet. There are no copied registry files to merge.

The controls use shadcn’s Base UI composition and Nova styling, with ordinary semantic CSS variables for [application branding](/docs/ui/customize). Existing theme variables are respected through CSS; build-time `components.json` settings are not read by an installed npm package.

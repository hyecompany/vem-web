While moving, text fades gently at the edges of its available space. The stationary label and the containing control stay crisp.

The component inherits typography and color. In a flex row, give the text space to shrink; avoid a parent whose minimum width is its entire content.

## Activate it from the whole control

Add `data-vem-overflow-trigger` to a containing button or option. Hovering or focusing that control activates the label. A parent with `data-highlighted` also activates it, so keyboard highlighting in a combobox works.

<Example package="ui" file="components.tsx" region="parent-trigger" />

Use this behavior with your existing interaction component. OverflowText does not create a button, option, tooltip, or additional focus stop.

## Keep the name accessible

The complete string stays in the accessible text. Motion respects the user's reduced-motion preference. Text is shortened at grapheme boundaries, preserving emoji and combined characters.

Do not make animation the only way to read important content. For touch and reduced-motion users, show the full selected name in nearby details, allow a popup label to wrap, or provide an accessible disclosure. A native `title` alone is not a dependable touch alternative.

Measurements update after resizing and font loading. The first server render contains the full string; the stylesheet constrains it until the browser can measure.

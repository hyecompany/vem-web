## Behavior and choices

Compose the parts you need; a card does not fetch data or make itself clickable. CardTitle is a styled container; place an appropriately ranked heading inside when the content needs one. CardAction puts a control beside the header.

Keep the action as a real button or link inside the card. Use your own layout around cards rather than teaching the component about application grids.

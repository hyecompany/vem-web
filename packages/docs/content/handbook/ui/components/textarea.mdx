## Behavior and choices

Use native textarea props, including `rows`, `required`, and `maxLength`. Keep its visible label even when the field has a placeholder.

For protected Vem Data drafts, use [managed text bindings](/docs/ui/components/data-bindings); an independent `useState` copy cannot follow selective disclosure withdrawal.

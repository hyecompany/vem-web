## Behavior and choices

InputGroup groups a control with InputGroupAddon content. Use InputGroupInput or InputGroupTextarea for the editable value. Supporting text uses InputGroupText, and a nearby action uses InputGroupButton.

Keep a visible label associated with the input. A prefix is context, not its accessible name. The addon’s `align` chooses `inline-start`, `inline-end`, `block-start`, or `block-end`.

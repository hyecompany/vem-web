## Behavior and choices

Use links for ancestors and BreadcrumbPage for the current page. Separators are decorative. The default navigation label is “breadcrumb”; provide a more specific label when necessary.

BreadcrumbLink accepts a normal `href`. Its `render` prop can compose with a router link without nesting interactive elements.

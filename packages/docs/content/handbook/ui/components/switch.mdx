## Behavior and choices

Use a switch for an on/off setting. `checked` and `onCheckedChange` give controlled behavior; `defaultChecked` gives an initial uncontrolled value. Native `name` and `value` participate in form submission.

The visible label describes the setting, not the next action. Keyboard users can focus it and press Space. Use `disabled` only when the setting cannot be changed.

Use a spinner beside a readable activity label. It inherits the current text color and has small, medium, and large sizes.

The defaults are medium size and the accessible label “Loading”.

## Give progress a name

When adjacent text already says what is happening, make the spinner decorative with `aria-hidden="true"`. For a standalone spinner, supply `aria-label` or `aria-labelledby` describing the activity.

A spinner communicates ongoing work; it does not manage requests, timing, or completion announcements. Keep the label tied to the actual activity, and use a status region when the result needs to be announced.

Reduced-motion preferences disable the animation while leaving its visual indicator and accessible label available.

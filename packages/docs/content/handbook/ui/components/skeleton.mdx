## Behavior and choices

Set the shape with ordinary CSS. Keep decorative placeholders hidden from assistive technology and describe the ongoing work once on their container.

Use a skeleton for initial acquisition, not to replace useful cached content. [QueryStatus](/docs/ui/components/query-status) can explain revalidation beside values already on screen.

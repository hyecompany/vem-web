Find a task, complete it, and edit its notes. Each step starts with one thing to try; optional controls let you change the service's response or your permissions.

<TaskBoardDemo />

## What belongs where?

**Vem UI** provides the buttons, tabs, fields, and task cards. **Vem Data** supplies queries, command progress, and protected edits. The application supplies the task layout and the meaning of its actions.

The task service runs in memory. For real network traffic and shared browser ownership, see [browser hosting](/docs/data/connect/browser-host).

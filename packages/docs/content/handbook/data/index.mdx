Vem Data is independently consumable as `@hyecompany/vem-data`. A feature uses named descriptions and shared React hooks; a backend adapter supplies identity, evidence, and operation semantics.

You can start at any recipe. Each guide names its prerequisites and links the deeper behavior it relies on.

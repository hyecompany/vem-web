Hye Vem brings shared application behavior and a consistent interface into reusable packages. Start with either package, or use them together.

| Package | Use it for |
| --- | --- |
| [Vem Data](/docs/data) | Share knowledge between screens, plan backend reads, coordinate commands, and protect drafts. |
| [Vem UI](/docs/ui) | Build controls, application navigation, and feedback with a consistent design. |

## See them work together

[Explore the task board](/docs/task-board): find a task, complete it, and edit its notes. Vem UI supplies the controls. Vem Data keeps the information and actions coordinated.

## Choose your next step

- **Building a screen?** Start with [UI components](/docs/ui/components) and [displaying data](/docs/data/build/display).
- **Connecting a service?** Define its resources in [Connect your data](/docs/data/connect).
- **Matching your application?** Set [branding and appearance](/docs/ui/customize).
- **Looking up an API?** Open the [Data reference](/docs/data/reference) or [UI reference](/docs/ui/reference).

## Start with the part you need

Hye Vem is a shared application framework. **Vem Data** is its first package: a browser and React runtime for applications that reuse data across screens, coordinate operations, and handle changes in access.

Install Vem Data on its own. You do not need a Vem UI kit, router, or the rest of a framework suite. Your application chooses its components and backend.

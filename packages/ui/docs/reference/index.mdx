The [component catalog](/docs/ui/components) links each component to its usage guide and working preview. Import components from `@hyecompany/vem-ui` and optional Data bindings from `@hyecompany/vem-ui/data`.

Use React’s `ComponentProps<typeof Button>` (or the relevant component) when you need to reuse its prop type. Your editor reads the declarations shipped with the package.

Include `@hyecompany/vem-ui/styles.css` once. Importing JavaScript does not insert the stylesheet. The core entry has no Data dependency; the `/data` entry requires Vem Data and its provider.

Implementation changes belong in the package, with public prop documentation and compiled examples updated together. See [contributing to the docs](/docs/data/reference/contributing) for the guide and snippet workflow.
